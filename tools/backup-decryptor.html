Backup Decryptor

Opens a Club Bar backup archive (.cbb) with one of the private keys it was sealed to.

Do this on a machine you trust, and offline if you can. The private key you paste below opens every backup sealed to it. Nothing is sent anywhere from this page - but the only way to be certain of that is to run it from a local copy with the network disconnected.

Download the .sql and import it through your host's database tool.

This archive also carries the installation's configuration. Download config.php — you need it only when restoring onto a different host. Without security.totp_encryption_key every admin's second factor fails against the database you just restored, and nobody can log in. Treat it as you would the private key you just used: it holds the database password. The `.sql` above already contains it as inert comments, so there is nothing extra to import.

Import table by table — when the .sql is over the upload limit

A club-sized database eventually outgrows what phpMyAdmin will accept in one upload. Each piece below is that table's section with the dump's own session settings already in front of it, so it imports on its own, in any order — foreign-key checks are off and the time zone is pinned to UTC. That pinning is the reason to take these rather than cut the file by hand: a piece imported without it lands every TIMESTAMP in the host's own zone, consistently, with nothing about the result looking wrong.
