## Summary

Add mandatory TOTP 2FA (RFC 6238) to the admin panel. Every admin must enroll before accessing the panel. Enforcement is session-based (no JWT introduced).

**Login has three outcomes:**
1. `totp_enabled = 1` → `{ requiresMfa: true }` → user enters TOTP code → full session
2. `totp_enabled = 0` → `{ requiresTotpSetup: true }` → mandatory setup screen → full session after enrollment
3. `POST /api/auth/mfa` success → full session (same response shape as existing login)

**Middleware enforcement:** `AdminSessionAuth` blocks all non-2fa endpoints when `$_SESSION['totp_setup_required'] = true`, returning `403 totp_setup_required`.

## Key Decisions (summary — see ADR-0026 for full rationale)

- **Mandatory**: No optional opt-in; all accounts gated
- **Session-based**: No JWT; pending state stored in `$_SESSION`
- **No recovery codes**: Admin reset is the recovery path
- **Admin reset**: Any logged-in admin can reset any user's 2FA (no role system)
- **Post-reset session**: Existing sessions remain valid until expiry; re-enrollment enforced on next login
